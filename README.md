# Bài kiểm tra tư duy lập trình

| Bài | Thư mục | Nội dung |
|---|---|---|
| 1 | [bai1-task-api](bai1-task-api/README.md) | REST API quản lý Task: NestJS + TypeORM/SQLite + Swagger (`/docs`) + Jest |
| 2 | [bai2-fibonacci](bai2-fibonacci/README.md) | Tính F(50) bằng Dynamic Programming + BigInt |
| 3 | [bai3-game-server](bai3-game-server/README.md) | Server game: tài khoản (bcrypt/JWT), Line 98, Cờ Caro online (Socket.IO) |

Yêu cầu: Node.js ≥ 18. Mỗi bài là một project độc lập:
```bash
cd bai1-task-api   && npm install && npm start   # http://localhost:3000/docs
node bai2-fibonacci/fibonacci.js
cd bai3-game-server && npm install && npm start  # http://localhost:3002
```
